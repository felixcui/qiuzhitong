# UI 优化总结 - 墨韵学府主题升级

| 文档版本 | V1.1 |
| :--- | :--- |
| **完成日期** | 2026-03-31 |
| **影响文件** | `web/app/globals.css`, `web/app/page.tsx` |

## 优化方向

设计主题：**「墨韵 · 深红」**
- 融合传统书院美学与现代数字界面设计
- 背景从冷白升级为暖米色点阵纸感纹理
- 强化空间层次感和信息密度

---

## 变更详情

### 1. globals.css — 设计系统升级

**颜色系统调整：**
- `--background` 从 `#F9FAFB`（冷灰白）升级为 `#F8F5F0`（暖米白）
- `--party-red` 从 `#D91F11` 调整为 `#C8190C`（更深沉有力）
- `--party-red-hover` 从 `#B91C1C` 调整为 `#A31409`
- 新增 `--party-red-deep`、`--surface-primary/secondary/card`
- 新增 `--party-gold`（`#C9861C` 深沉金色替代琥珀黄）
- 边框颜色升级为暖调 `--border-color: #E8E3DC`

**背景纹理：**
- 新增超细点阵径向渐变（28×28px）营造纸感
- `prefers-reduced-motion` 时自动关闭纹理

**阴影系统升级：**
- `--shadow-card-hover` 红色辉光加强（从 0.08 到 0.14 透明度）
- 新增 `--shadow-sidebar`

**动画优化：**
- `fadeInUp` Y轴位移从 10px 增至 12px，更有气势
- `scaleIn` 加入 Y轴位移，更立体
- 新增 `@keyframes shimmer` 骨架屏效果

**滚动条：**
- 暖棕色替代冷灰（`#D1C9BF`）

---

### 2. page.tsx — 组件升级

**SidebarItem（侧边栏项）：**
- 新增右侧计数 badge（显示该分类资源数）
- 活跃状态 badge 红色背景，非活跃状态灰底
- 竖线指示器改为渐变（从红到透明）
- 按钮 padding 微调（`py-3.5` → `py-3`）

**SiteCard（资源卡片）：**
- 新增悬停时左侧红色渐变边条（微动效）
- 图标容器加入边框（`border border-gray-100`），悬停变红色边框
- 右上角悬停时显示第一个 tag 徽章
- 外链图标按钮尺寸微调，圆角更精致（`rounded-lg`）
- hover 上浮从 `1px` 增至 `1.5px`

**SearchBar（搜索栏）：**
- 引擎切换从单独 pills 升级为 **Segmented Control**（白底圆角盒子）
- 搜索框 focus 状态加入三层效果：边框变色 + ring + 红色辉光
- 清除按钮图标尺寸微调

**CategorySection（分类区块）：**
- 标题左侧竖线从实色改为**渐变竖线**（`from-party-red to-party-red/30`）
- 加入分类资源数量 badge（暖米色背景）
- 右侧分隔线从实线改为**渐变消失**（`from-[#EDE8E1] to-transparent`）

**Hero 区域：**
- 新增大字幕装饰（「求知」两字，约 2.5% 透明度，视觉层次丰富）
- 新增资源统计行：「X 个精选资源 · X 个专业分类」
- 标题与副标题间距微调

**Header（顶部导航）：**
- Logo 圆角从 `rounded-lg` 升级为 `rounded-xl`
- 新增桌面端资源计数 pill（右上角灰底显示）
- "关于我们"悬停背景改为暖色调 `#F0EBE4`

**Sidebar（侧边栏）：**
- 顶部新增资源汇总统计（"X 个分类 · X 个资源"）
- 背景调整为暖调半透明
- 边框颜色改为暖调

**DetailModal（详情弹窗）：**
- 顶部条从纯红改为**渐变条**
- 图标容器改为渐变背景，加边框
- tags 区域完整展示（最多3个）
- 关闭按钮更小巧（`size={18}`）
- 弹窗阴影升级为 `shadow-float`

**AboutModal（关于弹窗）：**
- 弹窗加 `border border-[#EDE8E1]`
- 功能卡片背景改为暖调 `#F8F5F0`，加边框
- Logo 圆角、关闭按钮升级
- 底部 Motto 改为斜体衬线体
